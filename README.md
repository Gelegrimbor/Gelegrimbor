### 🧠 About Me

I automate the boring parts of media and business — radio dedications voiced by AI, Instagram DM funnels, podcast studio bookings — then build the apps on top.

- 🔭 **By day:** n8n workflows, internal tools and radio station sites at Media Prima Audio
- 🌙 **By night:** shipping AI side projects and selling n8n templates
- 🏠 **Homelab:** self-hosted n8n on my own Ubuntu box (*Barad-dûr*) behind a Cloudflare Zero Trust tunnel
- 🎓 Sigma School Full Stack bootcamp graduate (2025)
- 💬 **Ask me about:** n8n, Claude/Gemini API workflows, Supabase, self-hosting
